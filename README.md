# AutoHub-Vehicle-Marketplace  
#### A marketplace for new model automobiles, May 2025  
#### By **Bethwel.kc, Castro Baraka, and Osteen Otieno**

## Description  
AutoHub-Vehicle-Marketplace is a web application that showcases various models of new vehicles. Users can browse through a collection of car listings, view detailed information about each vehicle, and add their favorite cars to a personalized basket list. The platform also allows users to contact sellers directly for inquiries or negotiations. The application aims to provide a simple and user-friendly experience for anyone looking to explore and connect with automobile sellers.

## Setup/Installation Requirements  
* Visit the official website of AutoHub-Vehicle-Marketplace.  
* Create an account or log in with existing credentials.  
* Browse the vehicle listings, view details, add favorites to your basket list, or contact sellers.  
* No additional installation or setup is required.
